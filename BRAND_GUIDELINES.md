# Fuzara Technologies: Brand Guidelines & Visual Ecosystem

## Corporate Hierarchy
Fuzara Technologies operates as a multi-disciplinary tech ecosystem with specialized arms defined by distinct visual "shifts" while maintaining a shared core geometry.

1.  **Fuzara Technologies (Parent)**: The central hub for innovation and enterprise strategy.
2.  **Fuzara Drone Masters**: Specialized in next-generation aerial diagnostics and fleet management.
3.  **Amenic Films**: The cinematic and visual storytelling production arm.
4.  **Fuzara Dev**: The development arm that includes CashCraft

---

## Core Logo Geometry: "The Hex-Flow"
The core branding is built around a central **Hexagonal Core** (representing stability and compute power) surrounded by three **Liquid Drop Nodes** in a rotational lockup (representing fluidity, energy, and constant evolution).

---

## Visual Identity Mapping: Logo Lockup & Color Shift

### 1. Fuzara Technologies (Parent Core)
*The system default. Serious, professional, and vibrant.*
- **Midnight Navy**: `#0B132B` (Backgrounds, Typography)
- **Titanium Silver**: `#B2B2B2` (Secondary details, Wireframes)
- **Vibrant Teal**: `#00FFC2` (Action elements, Highlights)

### 2. Fuzara Drone Masters
*The industrial shift. High visibility, tactical, and rugged.*
- **Charcoal Grey**: `#2D2D2D` (Structural base)
- **High-Vis Orange**: `#FF6B00` (Safety markers, HUD alerts)

### 3. Amenic Films
*The cinematic shift. Atmospheric, deep, and mood-centric.*
- **Cinematic Teal**: `#003D3D` (Key visual tone)
- **Deep Shadows**: `#080808` (Base darkness)

### 4. Fuzara Dev (Dev Arm)
*The high-performance shift. Extreme precision, cyberpunk aesthetic.*
- **Vantage Black**: `#000000` (The ultimate base)
- **Neon Green**: `#39FF14` (Data streams, Success states)
- **Neon Blue**: `#00FFFF` (Secondary logic, Active states)

## Directory Structure
Asset management is centralized in the `/assets/branding/` directory:
- `fuzara_core/`: Master logos and primary brand assets.
- `drone_masters/`: Tactical assets and industrial UI elements.
- `amenic_films/`: Cinematic textures and visual media.
- `fuzara_dev/`: UI component libraries and SaaS assets.
